# Istanbul Restaurant Website

An eight-page student front-end project for Istanbul Turkish Taste in Astana.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
HTML, CSS and plain JavaScript are used with locally included Bootstrap assets.
There is no backend, database, real ordering or payment service.

## Pages and functionality

- Home: restaurant information and a random menu suggestion with a link to the menu.
- Menu: 18 dishes rendered from an array; connected name, category and maximum-price filters; matching count, no-results message and filter reset.
- Basket: add dishes, increase/decrease quantities, remove a line, clear, calculate line subtotals and the total, review and confirm a demonstration order.
- Visit: name, email, telephone, date, time, guest count and related fields; field-level validation, first-error focus, live choices and demonstration summary.
- Feedback: form validation, rating, character counter and local review cards with dates and removal.
- FAQ: search questions, result count, reset and a validated question-preparation form.
- Gallery: centred photo viewer, Previous/Next controls, arrow keys and Escape to close.
- About and Colophon: restaurant and project information with the shared navigation.

## Data and states

The menu array has 18 objects with `id`, `name`, `category` and `price`.
Prices are estimates in tenge; confirm current prices and availability with the restaurant.
Only basket item IDs are saved in localStorage. If storage is unavailable, the basket works on the current page and displays a notice.
Contact details, form values and reviews are not saved to browser storage or sent to a server.
Reviews disappear on reload. Repeated submission of the same last review does not create a second card.
Checkout clears the basket after local confirmation and gives a temporary `DEMO-` reference.
The restaurant does not receive this order and no payment is taken.

## JavaScript structure

| File | Responsibility |
| --- | --- |
| `js/main.js` | Shared DOM helpers, local date and basket storage/navigation |
| `js/home.js` | Random dish suggestion |
| `js/menu.js` | Product data, rendering, filters, basket and demo checkout |
| `js/forms.js` | Reusable validation and form interaction |
| `js/visit.js` | Visit date/time setup |
| `js/feedback.js` | Rating and local reviews |
| `js/faq.js` | FAQ search and question form |
| `js/gallery.js` | Photo viewer |

Scripts load with `defer` and use strict mode. No jQuery, application framework, inline event handlers or server-side code are used.
